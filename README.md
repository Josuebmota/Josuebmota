### What I'm building

**[Marvin](https://github.com/Josuebmota/Marvin)** — scaffolds a project's knowledge base for
working with AI agents, in a way that survives switching tools and switching LLMs. One source of
truth, thin adapters per tool, and agent memory versioned **inside the repository** instead of
buried in your user profile. A single Node file, zero dependencies.
